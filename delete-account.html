계정과 데이터 삭제

만나 (앱 패키지: kr.manna.app)

계정을 지우는 가장 빠른 방법은 앱 안에서 직접 지우는 것입니다. 확인을 두 번 거치면 그 자리에서 삭제되고, 따로 기다릴 필요가 없습니다.

앱에서 삭제하기

  1. 만나 앱을 열고 로그인합니다.
  2. 아래 내 정보 탭으로 이동합니다.
  3. 맨 아래 계정 삭제를 누릅니다.
  4. 안내를 읽고 두 번 확인하면 즉시 삭제됩니다.

잠시 쉬고 싶은 것이라면

내 정보 탭의 "소개 받는 중" 스위치를 끄면 아무에게도 새로 소개되지 않습니다. 기존 매칭과 대화는 그대로 남고, 언제든 다시 켤 수 있습니다. 삭제와 달리 되돌릴 수 있습니다.

앱에 접속할 수 없다면

기기를 잃어버렸거나 앱을 이미 지웠다면 아래 이메일로 요청해 주세요.

  • 보내실 곳: manna.app.help@gmail.com
  • 제목: 계정 삭제 요청
  • 본문: 가입에 사용한 이메일 주소

가입한 이메일 주소에서 보내 주세요. 다른 사람이 남의 계정을 지우는 것을 막기 위해 본인 확인을 거칩니다. 확인 후 영업일 기준 7일 이내에 처리하고 결과를 회신합니다.

무엇이 지워지나요

즉시 삭제남는 것
계정과 로그인 정보
프로필(이름·나이·소개글·질문 답변·신앙 등 모든 항목)
업로드한 사진 전부
매칭 내역과 주고받은 대화
관심·넘김 기록, 차단 목록
보석 잔액과 사용 내역 		이용자에 대한 신고 기록
(신고자와 피신고자를 식별할 수 없는 형태)

신고 기록을 남기는 이유는 하나입니다. 계정을 지우면 신고 내용까지 사라지는 구조라면, 신고를 받은 사람이 계정을 지우고 다시 가입하는 것만으로 기록을 없앨 수 있게 됩니다. 신고한 사람을 보호하기 위해 내용만 남기고 누가 누구인지는 끊습니다.

법령이 일정 기간 보존을 요구하는 기록이 있는 경우(예: 유료 결제가 도입된 이후의 거래 기록) 해당 기간 동안 분리 보관한 뒤 파기합니다. 현재 서비스는 결제를 제공하지 않습니다.

되돌릴 수 있나요

없습니다. 삭제는 즉시 이루어지고 복구할 방법이 없습니다. 대화 기록을 가지고 계시려면 삭제 전에 앱의 내 정보 → 내 데이터 내보내기로 파일을 먼저 저장해 주세요.
